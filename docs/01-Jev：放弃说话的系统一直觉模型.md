# Jev：放弃说话的系统一直觉模型

> 日期：2026-09-20
>
> 来源：AI 开发者圈子里爆火的一个新模型——TypeSafe AI 发布的 Jev

最近 AI 圈子里在传一个叫 Jev 的模型，创始人 Diogo Almeida 是 OpenAI 出来的，当年 ChatGPT 背后那套 RLHF 训练流程他也是核心贡献者之一。但这个模型最让人意外的地方，不是它有多强，而是它彻底放弃了"说话"这件事。

传统大模型——GPT、Claude、Gemini——本质都是"生成文字"，一个一个 token 往外蹦。Jev 不一样。它不生成自然语言、不写代码、不聊天，只做一件事：你给它一段状态信息，加上你预先定义好的问题，它直接返回一个结构化的判断。官方把它叫作"System One Model"，借的是卡尼曼《思考，快与慢》里"系统一"那个概念——快速、直觉式的判断，不解释。

它的输出只有三种原语：

- **Choice**：从你预设的选项里选一个，最多支持 255 个选项
- **Score**：在一个范围内打分，附带置信度
- **Noul**：返回是/否的概率

打个比方，一封客服邮件进来，它可以同时判断"该分给哪个部门 / 紧急程度 / 退款风险 / 是否需要人工介入"，返回的是概率和选项，不是给你解释一段话。

速度上，官方说在结构化决策任务里比前沿大模型快 20 到 200 倍，端到端延迟 70 到 500 毫秒。成本压得更狠：输入每百万 token 0.042 美元，输出免费——因为它根本不生成 token。有人拿它实时操控《毁灭战士》，每秒约 10 次决策，每小时成本大概 7 美元。

模型名字也有意思。Jev 取自 19 世纪经济学家 William Stanley Jevons，也就是"杰文斯悖论"的提出者：效率提高、成本下降，需求反而暴增。TypeSafe 的意图很明确——他们不想造一个超级 App，他们想让"智能判断"便宜到可以被塞进软件的每一个角落，像早期互联网那样分布式地存在。

不过有个关键点值得拎出来：它宣传的"零幻觉"，不是说它不会判断错，而是说它的输出永远不会超出你预先定义的格式和选项范围。它可能选错，但不会像 LLM 那样"胡编一段不存在的 JSON 或文字"。

## 我看到的几个东西

**第一，方向感变了。** 这两年大家都在卷"模型能不能写长文、能不能像人一样聊天"。Jev 反着来——直接放弃"说话"，只做"判断"。这是一种很清醒的取舍：当一件事被做得足够便宜、足够快、足够结构化，它就不再是"AI 能力"，而是基础设施的一部分，像水电一样。

**第二，"分布式智能"这个老命题又回来了。** 移动互联网早期大家也聊"把智能塞进每一个角落"，后来大家都跑去卷超级 App 了。Jev 这种产品形态，是在押一个不一样的未来：判断能力作为可调用的原子服务，到处嵌。

**第三，也是最让我多想一点的——"零幻觉"这个营销词，其实是在重新定义"幻觉"。** 它把幻觉从"判断错"重新定义为"输出超出约定格式"。这种重新定义很聪明，但也容易让人误读。一个会选错的工具和一个会胡编的工具，风险根本不是同一回事。选错可以靠流程兜底，胡编可能直接污染下游系统。所以真正落地的时候，"输出永远在格式内"是底线，"选得对不对"才是要长期解决的问题。

## 留给自己的问题

1. 当判断的成本低到这个程度，我的工作里有多少"判断环节"其实是多余的？
2. 如果判断被外包给这种小模型，"判断力"这个能力本身，值多少钱？
3. 我们这代人正在见证的，到底是"AI 越来越像人"，还是"AI 越来越不像人"？

这是一件值得记下来的事——不是因为它今天有多火，而是因为它代表了一个方向的拐点。
